### 🛡️ SilentVerify — Passive CAPTCHA Detection System
*Machine Learning · Behavioral Analysis · Flask*

A behavioral detection system that classifies sessions as legitimate or automated **without** showing users a CAPTCHA challenge — removing a common source of user friction while still catching bots.

**How it works:**
`User Interaction → Behavioral Feature Extraction → ML Model → Classification → Flask App → MySQL`

- Simulated and collected 1,000+ human/bot sessions using Selenium
- Engineered behavioral features: idle time, click cadence, form-fill timing, mouse/interaction patterns
- Trained and evaluated a classification model, tuned for accuracy and low false-positive rate

**Results:**
- **92% classification accuracy**
- **75% reduction in user friction** by eliminating traditional CAPTCHA interaction

`Python` `Flask` `Scikit-learn` `Selenium` `MySQL`
[GitHub Repository](https://github.com/Jayesh-Jadhav6/SilentVerify)

### 🎯 IntelliPrep — AI Interview Preparation System
*Machine Learning · NLP · Computer Vision · Full-Stack*

A modular, Flask-based platform that helps candidates prepare for interviews through role-specific questions, automated answer evaluation, resume analysis, and video-based soft-skill feedback.

**Core modules:**
- **User Management** — registration, login, sessions, interview history
- **Role-Specific Questions** — job-role selection and question classification
- **Answer Evaluation** — text similarity, grammar, content quality, and scoring using TF-IDF and cosine similarity
- **Resume Analysis** — skill extraction, job-description matching, ATS scoring, and skill-gap identification via semantic similarity
- **HR Video Analysis** — facial expression, posture, and confidence signals via computer vision
- **Performance Dashboard** — scores, progress trends, and feedback summaries over time
